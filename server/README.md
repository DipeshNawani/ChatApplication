# QuantumBytes Chat Server

Run all commands from the `quantumbytestask` folder.

## Local setup

```powershell
.venv\Scripts\python.exe -m pip install -r server\requirements.txt
Copy-Item server\.env.example server\.env
```

DEV_MODE is test-only and cannot be enabled through `server/.env`. Normal
runs use a random `JWT_SECRET` of at least 32 characters.

The local development database is managed by Alembic. To reset it and create
the current schema:

```powershell
if (Test-Path server\data\chat.db) { Remove-Item server\data\chat.db -Force }
.venv\Scripts\python.exe -m alembic -c server\alembic.ini upgrade head
```

Start the server:

```powershell
.venv\Scripts\python.exe -m uvicorn app.main:socket_app --app-dir server --env-file server/.env
```

`JWT_EXPIRE_MINUTES` defaults to 60. There are no refresh tokens. Uploaded
files are written under `UPLOAD_DIRECTORY`; the Render filesystem is
ephemeral, so deployed storage is not durable.

For hosted deployment, Render uses root `render.yaml` and `.python-version`.
Set its `DATABASE_URL` to the Supabase PostgreSQL connection URI and keep
`JWT_SECRET` generated by Render. `TRUST_PROXY_HEADERS=true` is appropriate
only behind Render's trusted proxy; do not set it for an internet-exposed
local server.
